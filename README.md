# Web Development Lab

This repository contains my Programming for Web Development - I Laboratory practicals (P1 to P13).

I have kept each practical in its own folder. The HTML and CSS are separate so it is easier to find the page structure and the styling while practising.

## Practicals

| Practical | Topic |
|---|---|
| [P1](P1/README.md) | Project folder and terminal navigation |
| [P2](P2/README.md) | Portfolio repo with an initial commit |
| [P3](P3/README.md) | Feature-branch Git workflow |
| [P4](P4/README.md) | GitHub README and version tags |
| [P5](P5/README.md) | Semantic bio page |
| [P6](P6/README.md) | Full portfolio page structure in semantic HTML |
| [P7](P7/README.md) | Design tokens and typography system in CSS |

| [P9](P9/README.md) | Responsive navbar and card grid using Flexbox |
| [P10](P10/README.md) | Portfolio header and footer with advanced Flexbox |
| [P11](P11/README.md) | Newspaper-style three-column layout with CSS Grid |
| [P12](P12/README.md) | Portfolio projects grid with advanced CSS Grid |
| [P13](P13/README.md) | Choosing between Flexbox and Grid for a shared layout |

## Folder format
Each practical folder contains a `README.md`, an `index.html` page and a separate `style.css` stylesheet.

## How to view
Open a practical folder and open its `index.html` file in a browser. No framework or extra setup is needed for these basic exercises.
