P4: GitHub README and version tags

A small version-notes page with links to the project sections.

What I worked on

This practical covers writing a useful project README and marking a version with a Git tag. Tags make it easier to identify a particular saved version later.

Notes / example

git add README.md
git commit -m "Write project README"
git tag -a v1.0 -m "First version"
git push origin main
git push origin v1.0
