# P10: Portfolio header and footer with advanced Flexbox

## Aim
This practical focuses on aligning the portfolio header and footer. Flexbox helps keep the logo, navigation and footer details lined up when the available width changes.

## What I did
- Went through the practical topic and tried the example.
- Kept the HTML and CSS in separate files.
- Made a few notes so I can revise the steps later.

## Files
- `index.html` – the page for this practical.
- `style.css` – the external stylesheet.

## Commands / points to remember
```text
display: flex;
align-items: center;
justify-content: space-between;
gap: 1rem;
```

The practical page is ready. Open `index.html` in a browser to check the layout.
