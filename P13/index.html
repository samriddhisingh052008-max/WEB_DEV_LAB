P13: Choosing between Flexbox and Grid for a shared layout

A small comparison of two CSS layout tools.

Flexbox

Flexbox works well when I want to line items up in a row or a column. A navigation bar is a common example.

.nav { display: flex; gap: 1rem; }

CSS Grid

Grid is useful when I need to organise content in rows and columns, like a gallery of project cards.

.projects { display: grid; grid-template-columns: repeat(2, 1fr); }
