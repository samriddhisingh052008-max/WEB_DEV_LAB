# P13: Choosing between Flexbox and Grid for a shared layout

## Aim
I compared where Flexbox and Grid are useful. Flexbox works well for arranging items in one direction, while Grid is handy when I need rows and columns together.

## What I did
- Compared a one-direction layout with a two-dimensional layout.
- Kept the HTML and CSS in separate files.
- Added a small example showing when each option is useful.

## Files
- `index.html` – the comparison page.
- `style.css` – the external stylesheet.

## Points to remember
```css
/* Flexbox: one-dimensional layout */
display: flex;

/* Grid: rows and columns */
display: grid;
```

## Result
The page shows two simple cards side by side on a wide screen and stacked on a smaller screen.

## What I learned
Flexbox is a good fit for arranging items along one axis. Grid is useful when I need to control rows and columns together.
